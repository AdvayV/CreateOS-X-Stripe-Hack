# CartPilot

An agentic quick-commerce assistant that proves its basket before asking to spend.

The differentiator is recovery under changing commerce conditions: natural-language intent becomes executable code, code compares canonical merchant offers in CreateOS, independent checks verify it, and exact human permission is revoked when stock or prices change. The agent then replans and requests fresh permission.

The demo has three fictional merchants, 36 products, fault injection, readable execution evidence and a clearly labeled wallet simulator. Stripe Projects supplies the provider integration. Optional Link Agent Wallet and Stripe MPP code is test-only; live settlement is not part of this build, and Link test settlement remains unverified.

CreateOS supplies persistent microVMs, isolated execution, controlled egress, file transfer, browser automation, pause/resume and application hosting. Existing credits fund CreateOS usage; no paid plan upgrade or credit top-up is authorized. AI usage has a $2 maximum approval with no automatic paid fallback.

See DEMO.md for the presentation and README.md for setup, boundaries and verification.
